# 実装計画 (Implementation Plan) - united_award_monitor_fix

スプレッドシート非公開（限定共有）状態を100%維持したまま、手動介入なしでリアルタイム全自動連動監視を行うための技術仕様と修正手順。

## 1. 基本方針
- **身バレ防止の徹底**: Googleスプレッドシートの「Webに公開」や「リンクを知っている全員に公開」は**絶対に行わない**。
- **完全非公開共有**: GCPサービスアカウントのアドレスのみを閲覧権限で共有に追加し、安全に認証フェッチを行う。
- **手動偽装の完全排除**: 予備データ（フォールバック）への安易な書き換え依存を廃止し、取得失敗時はエラーログを正確に記録する。

## 2. 実装コンポーネント

### 2.1 スプレッドシートリアルタイムフェッチエンジン (`united_monitor.py`)
- GCPサービスアカウントキー (`GCP_SERVICE_ACCOUNT_KEY`) のパースロジックの強化
- `gspread` による直接オブジェクト読み込みの安全化
- `有効` / `停止` の動的フィルタリングの確実な適用

### 2.2 GitHub Actions ワークフロー (`.github/workflows/run_monitor.yml`)
- 現行: `cron: '0 22,23,0-14 * * *'` (JST 7:00〜23:00 毎時実行)
- 9/1予定: `cron: '0 * * * *'` (24時間運用)
- 無料枠（月2,000分）範囲内での安定稼働検証
