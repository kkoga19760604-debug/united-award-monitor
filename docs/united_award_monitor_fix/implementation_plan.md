# 実装計画: United航空 特典航空券自動監視システムの修正と機能強化

United航空特典航空券（ANA便利用）の自動監視システムにおける「スプレッドシート読み込み失敗問題」「乗継便（伊丹・羽田経由等）を含む7kマイル特典空席の不検知問題」を根本解決し、12ヶ月分の全自動監視とDiscordまとめ一括通知を実現します。

## 主な変更点

### 1. スプレッドシート読み込みの堅牢化 (`get_sheet_targets`)
- 複数のCSV取得URL（gviz, export, pub等）を順次フォールバック試行。
- 万が一Google側のアクセスエラー（400 Bad Request / アクセス制限等）が発生した場合でも、デフォルト監視路線（`KMJ -> SDJ` など）に安全にフォールバックしてシステム停止を回避。
- 空港コード抽出（"KMJ (熊本)" ➔ "KMJ"）およびステータス "有効" 行のフィルタリング処理を強化。

### 2. 12ヶ月先までの自動範囲拡張
- 検索期間を今月から向こう12ヶ月分（今月〜11ヶ月先まで）に自動設定。

### 3. 直行便 ＋ 乗継便（接続便）の100%全自動空席検索ロジック
- ハブ空港 `["ITM", "HND", "NGO", "KIX", "FUK", "CTS", "OKA"]` を定義。
- 出発地・目的地間の直行便のみならず、指定ハブを経由する乗継便（同日の第1区間・第2区間の双方が空席）を自動組み合わせ判定。
- ANA/United 照会API および Playwright (`--disable-http2` / Stealth設定) のハイブリッドエンジンで確実にデータを取得・判別。

### 4. 万能パースロジックと日付判定機能
- あらゆるレスポンス形式から空席（"OK", "LOW", "○", "△", "AVAILABLE", "true", "7k" 等）を再帰的・網羅的に判定する `parse_availability_universal` を実装。
- 「土日」「金土日祝」「すべて」「特定の年月日」など多様な日付条件を祝日判定付きで高精度にパース。

### 5. @everyone メンション付き Discord まとめ一括通知
- 検出された全空席を路線ごとに【直行便 空席日程】と【乗継便 空席日程 (経由地: 伊丹, 羽田等)】に整理して1つのEmbedレポートにまとめ、`@everyone` メンションを付与して送信。
- 前回送信データとの MD5 ハッシュ照合により、重複通知を自動スキップ。
