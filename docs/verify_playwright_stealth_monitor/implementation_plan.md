# ユナイテッド航空 特典空席自動判定（案A: Playwrightステルス）検証計画

## 概要
ユーザー様のご指定に基づき、**完全無料（0円）・Mac電源OFF（クラウド自動実行）**で「空席がある時のみDiscord通知（ない時は無言）」を実現するための**案A（Playwright + ステルスブラウザによる空席自動判定）**の実現可能性を厳格に検証します。

Akamai Bot Manager等の防御壁を突破できるかを客観的な生ログ・エビデンスで検証し、突破が困難と判明した場合は一切の誤魔化しなく報告の上、即座に**案B（ワンタップ公式確認リンク通知）**へ切り替えます。

---

## ユーザー確認・重要事項
> [!IMPORTANT]
> - **完全無料（追加費用0円）の厳守**: 有料プロキシや有償APIは一切使用しません。
> - **事実・生ログの完全開示**: テスト実行時のレスポンス（HTTPステータス、画面キャプチャ、取得成否）を加工せずそのまま提示します。
> - **早期切り替え**: クラウドIP遮断等でデータ取得が不可能な場合は、速やかに案Bへシフトします。

---

## 検証・実装ステップ

### 1. 検証用ステルスブラウザスクリプトの作成
- `playwright` および `playwright-stealth`（または最新フィンガープリント偽装設定）を用いたテストスクリプトを作成。
- スプレッドシート記載の有効路線（例: `KMJ` ➡️ `SDJ`、日付: 直近の金曜日など）の特典航空券検索URLを開く。
- ページ内のフライト一覧（便名、出発/到着時刻、必要マイル数）のDOM要素または通信APIレスポンスの取得を試みる。

### 2. 実行テストとログ収集
- ヘッドレスモード（サーバー環境想定）で実行し、以下の項目を記録・確認する：
  1. ページ読み込みステータス（200 OK か、403 Access Denied か）
  2. Akamai CAPTCHA / Bot検知チャレンジの発生有無
  3. フライト結果要素の描画・取得成否
  4. 画面スクリーンショット（証拠画像）の保存

### 3. 判定と方針決定
- **【成功（案A採用）】**:
  - フライト情報が正常に抽出でき、空席の有無が判定できた場合 ➔ 空席時のみDiscord通知する本番監視スクリプト（GitHub Actions用）の実装へ進む。
- **【失敗（案Bへ即時切替）】**:
  - 403ブロックまたはCAPTCHA等でデータ取得が不可能な場合 ➔ 生ログを提示し、案B（ワンタップ公式直リンク通知）の最適化へ切り替える。
