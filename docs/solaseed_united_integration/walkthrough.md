# 成果と変更点サマリー (Walkthrough)

ユナイテッド航空およびソラシドエアの特典航空券を、1つのシステム（1つのスプレッドシート）でまとめて全自動監視・時間帯フィルタリング・Discord一括通知を行う「統合自動監視システム」への拡張・改修が完了いたしました。

## 変更点

### 1. スプレッドシートのプルダウン・項目拡張対応

- **対象航空会社列の追加**: `すべて`, `ユナイテッド`, `ソラシド` のプルダウン選択に対応。
- **希望時間帯列の追加**: `全時間帯`, `午前便` (〜12:00), `午後便` (12:00〜), `夕方以降` (17:00〜), `夜便` (19:00〜) のプルダウン選択に対応。
- **詳細日付・期間条件**: `金土日`, `日祝`, `土日祝`, `全日`, `YYYY-MM-DD`, `◯月以降` など柔軟な条件判定を統合。

### 2. ソラシドエア (Solaseed Air) 照会エンジンの追加

- ソラシドエア運航便（SNJ/SNAコードシェア便含む）の12ヶ月通年空席データを全自動高速照会するモジュールを追加。

### 3. Discord Embed 通知のデザイン強化

- **ユナイテッド航空**: ✈️ 【United特典空席 12ヶ月全レポート】 (ユナイテッドブルー)
- **ソラシドエア**: 🥑 【ソラシド特典空席 12ヶ月全レポート】 (ソラシドグリーン)
- それぞれの空席結果を自動的にグループ化し、複数Embedに分割して見やすく通知。
